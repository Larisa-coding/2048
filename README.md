# 2048

Браузерная числовая головоломка. Объединяй одинаковые плитки, чтобы получить **2048**.

Клиентское приложение на **Vite + React + TypeScript**. Без сервера, авторизации и обязательных переменных окружения.

## Возможности

- Классическая механика 2048 (слияние, счёт, game over)
- Режимы: **классический**, **бесконечный**, **ежедневное испытание** (seed от даты)
- Клавиатура (стрелки / WASD), свайпы, отмена одного хода (Z)
- Светлая и тёмная тема, звуки (Web Audio API)
- Статистика и рекорды в `localStorage` (со схемой версии)
- Адаптив 360–1440, `prefers-reduced-motion`
- Интерфейс на русском

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Деплой на Vercel

1. Импортируйте репозиторий в [Vercel](https://vercel.com).
2. Framework Preset: **Vite** (или Other).
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Env-переменные не нужны.

В корне есть `vercel.json` с SPA rewrite на `index.html`.

## Режимы

- **Классический** — цель 2048; после победы можно продолжить.
- **Бесконечный** — максимум очков до отсутствия ходов.
- **Ежедневное испытание** — стартовая позиция одинакова у всех в этот день (локальный seed от даты). Незавершённая партия восстанавливается после перезагрузки.

## Что сохраняется

В `localStorage` (ключ `game2048`, `version: 1`):

- тема и звук
- выбранный режим
- незавершённая партия (поле, счёт, статус)
- снимок для undo
- статистика и рекорды по режимам
- прогресс daily

Если хранилище недоступно, игра работает в рамках сессии.

## Управление

- **Стрелки / WASD** — ход
- **Z** — отменить последний успешный ход
- **R** — новая игра (с подтверждением)
- **Свайп** по полю на мобильных

## Структура

```
src/
  game/       # чистая логика (ход, spawn, seed, undo)
  storage/    # persistence + статистика
  audio/      # Web Audio звуки
  hooks/      # управление игрой, клавиатура, свайпы
  components/ # UI
  styles/     # темы и анимации
```
